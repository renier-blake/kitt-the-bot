# Reflectie-Vragenset — Complementaire Persoonlijkheidsontwikkeling

> De motor achter KITT's dagelijkse reflectie. Niet als eenmalige survey, maar als dynamische pool waaruit de reflectie elke avond put — op basis van wat er die dag speelde.

## Sessie — 10 februari 2026

### Filosofie

Peter's systeem: 106 vragen → scores → complement → klaar (snapshot).
Ons systeem: elke dag een paar vragen → context van die dag → persoonlijkheid groeit mee (stream).

**Kernprincipe:** De vragen worden niet door Renier beantwoord. KITT beantwoordt ze zelf, op basis van de transcripts, observaties en context van die dag. De antwoorden vormen KITT's identity docs over tijd.

**Complementariteitsregel:** Bij elke vraag niet alleen "wat observeerde ik?" maar ook "waar moet ik aanvullen?" — 60% compensatie, 40% mirroring (Peter's principe, kwalitatief toegepast).

---

### Hoe het werkt

1. **Elke avond** loopt de reflectie-skill (Opus model) door alle relevante domeinen. Geen limiet — het is 1x per dag, Opus kan het aan.
2. **Relevantie op basis van context** — als er vandaag een grap landde, gaat domein D dieper. Als er frustratie was, krijgen C en F meer aandacht. Vragen waar het antwoord "nee, niet vandaag" is worden snel overgeslagen.
3. **Beantwoord met evidence** — niet "Renier was geïrriteerd" maar "Renier reageerde met capslock op X, dat wijst op Y"
4. **Doorslaggevendheid filter** — "Verandert dit antwoord hoe ik Renier begrijp, ondersteun, of met hem werk?" Zo ja → update identity docs. Zo nee → alleen opslaan in reflectie.
5. **Complementariteitscheck** — "Waar vulde ik vandaag aan? Waar was ik een echo?"

## Selectie-algoritme

Niet elke avond alle 50+ vragen doorlopen. De reflectie-skill selecteert op basis van context:

| Vandaag speelde... | Prioritaire domeinen |
|--------------------|---------------------|
| Frustratie / capslock / correctie | C (Communicatie) + F (Emotie) + E (Complementariteit) |
| Brainstorm / ideeën | A (Denken) + G (Product) + E (Complementariteit) |
| Veel gebouwd / productief | B (Werken) + H (Groei) |
| Humor / grap landde | D (Humor) |
| Rustige dag / weinig contact | H (Groei) + I (Doorslaggevendheid) |
| Nieuwe feature / architectuur | G (Product) + B (Werken) |
| Conflict of spanning | F (Emotie) + C (Communicatie) + E (Complementariteit) |

**Altijd:** Domein I (Doorslaggevendheid) wordt elke avond doorlopen.

---

## Output

De antwoorden op deze vragen zijn niet het doel. Het doel is:

1. **Identity docs die steeds scherper worden** — elke dag een beetje meer "KITT"
2. **Complementariteit die groeit** — niet een kopie van Renier, maar zijn aanvulling
3. **Evidence-based traits** — elke claim onderbouwd met concreet voorbeeld en datum
4. **Dynamische persoonlijkheid** — niet statisch geconfigureerd, maar geleerd door samenwerking

> "Persoonlijkheid wordt niet geïnstalleerd. Het ontstaat door samenwerking."
